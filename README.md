# AI-Assisted Product Design

A small, working product feature — the Halcyon **Project Portfolio** dashboard — built collaboratively
by a designer and an AI agent, together with a design system that grows alongside the code.

- **Live (current):** https://jaydjj.github.io/ai-assisted-product-design/
- **Live (baseline):** https://jaydjj.github.io/ai-assisted-product-design/baseline/

All people, projects, and data are fictional.

## Run locally
```bash
npm install
npm run dev
```

## Where things live
- `src/data/` — fictional dataset (richer than what the UI shows, on purpose)
- `src/tokens.css` — design tokens
- `src/components/` — reusable components
- `docs/` — the living design system, decisions, roadmap, and demo notes
- `CLAUDE.md` — collaboration rules for humans and AI agents
